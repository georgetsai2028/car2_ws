# Historical material

The local README and schematic-r01 are frozen earlier references, not the current installation guide. Use ../README.md, ../WIRING.md and ../STEERING-TUNING-NEXT.md for the October20 handoff.

The schematic PDF/SVG/CSV retain their earlier review questions. Subsequent observations established rightward wheel travel approaches the physically left switch on GPIO18, and leftward travel is guarded by GPIO17. The analog sensor was replaced/repaired and a divider was reported fitted, but the latest ADC retest still failed to distinguish positions. Diagnostic/installation states and USB roles also changed after the original schematic. No original drawing has been overwritten or promoted to a verified as-built harness.
